HRMS Labour Attendance API

Spring Boot backend for worker attendance, active Redis clock-ins, overtime calculation, monthly settlement, Supabase PostgreSQL, CORS, and structured API errors.

Vercel does not provide an official Java/Spring Boot runtime. This deployment is a project landing page; run the API with Java 17 and Maven or deploy the backend to a Java host.

POST /api/attendance/clock-in POST /api/attendance/clock-out GET /api/attendance/active GET /api/attendance/log?workerId=1&from=2026-01-01&to=2026-01-31 GET /api/overtime/summary/1?month=2026-04 POST /api/overtime/settle/1?month=2026-04
